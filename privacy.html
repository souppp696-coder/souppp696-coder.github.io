プライバシーポリシー

「個人用スクリプト」（以下「本アプリ」）は、運営者本人だけが使う個人用のプログラムです。

1. 取得する情報

本アプリは、運営者本人が許可した範囲で、運営者本人の Google アカウントの Google ドライブ、Google スプレッドシート、Google ドキュメント、Google カレンダー、Gmail の下書きのデータにアクセスします。

2. 情報の使い道

本アプリは、取得した情報を、運営者本人の業務の資料の作成と予定の管理のためだけに使います。

3. 第三者への提供

本アプリは、取得した情報を第三者に提供・販売しません。広告にも使いません。

4. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の使用と移転は、限定使用の要件を含め、Google API サービスのユーザーデータに関するポリシーに従います。

5. アクセスの取り消し

本アプリへのアクセスの許可は、Google アカウントの「サードパーティ製のアプリとサービス」の画面からいつでも取り消せます。
